API Router × CC Switch

如何接入 Claude Code

适合什么场景

如果您想使用 Claude Code 或 Codex，但暂时不想购买它们的官方会员，可以先注册API Router账号， 在API Router中创建可用的 sk-... 令牌，然后通过 CC Switch 切换访问地址：把原来的官方地址切换为API Router地址 https://apirouter.ai。 这样 Claude Code 或 Codex 的请求就会通过API Router进行转发。

准备信息

你需要准备什么

  • 一个可登录的API Router账号
  • 一个可用的 CC Switch 客户端
  • API Router中可创建令牌的权限

最终要填进 CC Switch 的两项内容

  • API Key：API Router生成的 sk-... 密钥
  • 请求地址：https://apirouter.ai

特别注意

  • 请求地址不要以斜杠结尾
  • 不要把令牌名称误填到 API Key 位置
  • 如果有 Claude 专用分组，优先选支持 Claude 的分组

操作步骤

1下载并安装 CC Switch

打开 CC Switch 的 GitHub 仓库 ，进入右侧或页面顶部的 Releases，下载适合自己系统的最新版本。

Windows 推荐下载 CC-Switch-v{version}-Windows.msi 安装包； 如果不想安装，也可以下载 CC-Switch-v{version}-Windows-Portable.zip 便携版。
macOS 推荐使用 Homebrew 安装： brew tap farion1231/ccswitch，然后执行 brew install --cask cc-switch；也可以在 Releases 下载 CC-Switch-v{version}-macOS.dmg。
Linux 按发行版选择 .deb、.rpm 或通用的 AppImage 文件。Arch Linux 用户可以使用 paru -S cc-switch-bin 安装。

安装完成后先打开 CC Switch，确认能进入主界面。首次启动时，如果你本机已有 Claude Code 或 Codex 的配置，可以按软件提示导入现有配置；如果没有，后续直接新建供应商即可。

2进入API Router的令牌管理页面

登录API Router后，在左侧菜单找到 令牌管理，点击页面中的 添加令牌 按钮，开始创建一个新的访问令牌。

这一页的核心目标只有一个：生成一条后面可以复制到 CC Switch 的 sk-... 密钥。

3填写令牌基础信息

在“创建新的令牌”窗口中，优先填写以下几个字段：

名称 给令牌起一个容易辨认的名字，例如 cc-switch 或 我的 Claude 令牌。
令牌分组 选择一个支持 Claude 的分组。若你的平台有 Claude 专用分组，优先选择它；如果没有，选择管理员为你开放的可用分组。
无限额度 如果你希望先快速接入，可以保持开启；如果你的账号有额度管理要求，再按实际策略调整。
模型限制列表 一般可先留空，表示继承当前分组可用模型；只有你明确只想限制某些模型时再配置。

如果你选择了不支持 Claude 的分组，后续在 CC Switch 中即使填对了 API Key 和地址，也可能无法正常调用 Claude。

4创建并复制 SK 密钥

令牌创建完成后，你会在令牌管理列表里看到一条新的密钥记录。找到对应行中的 sk-... 字段，点击复制按钮，把整串密钥复制出来备用。

  • 你后面要填进 CC Switch 的就是这条完整密钥
  • 不要只复制令牌名称，也不要漏掉前缀 sk-
  • 复制后建议先保存在临时安全位置，避免重复查找

5在 CC Switch 中添加新供应商

打开 CC Switch，进入“添加新供应商”页面。按截图所示，把API Router作为一个新的服务提供方填进去。

供应商名称 可填写 API Router，也可以填你习惯识别的名称。
API Key 粘贴刚刚从API Router复制出来的完整 sk-... 密钥。
请求地址 填写 https://apirouter.ai

请求地址请直接填写 https://apirouter.ai，不要额外补 /v1，也不要在最后加 /。

6保存并测试

完成填写后，点击 CC Switch 的“添加”或保存按钮。保存成功后，尝试发起一次 Claude 请求，确认API Router已被成功接入。

  • 如果能正常返回回复，说明接入完成
  • 如果报认证错误，优先检查 API Key 是否完整
  • 如果报模型不可用，优先检查API Router令牌分组是否支持 Claude

推荐填写模板

供应商名称 API Router
API Key sk-xxxxxxxxxxxxxxxx
请求地址 https://apirouter.ai

常见问题

为什么我填了地址还是连不上？

先确认请求地址是否严格填写为 https://apirouter.ai。最常见的问题是地址后面多了斜杠，或者误填成了别的域名。

为什么 API Key 正确，但 Claude 还是不可用？

这通常不是密钥格式问题，而是令牌所在分组没有开放 Claude 模型。回到API Router，检查你创建令牌时选择的分组是否支持 Claude。

模型限制列表要不要填？

如果你只是为了尽快接入 CC Switch，建议先不填。等接入成功后，再按实际需要限制模型范围。

完成以上步骤后，你就已经把API Router成功接入到 CC Switch 中了。
